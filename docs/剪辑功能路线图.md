# MixedEditing 剪辑功能实现路线图

> 架构基调（已确认）：**全自建合成层** + **全速实时合成播放** + **分阶段多轮推进**。
> 音视频编解码与滤镜统一以 **FFmpeg（libav* + libavfilter）** 为内核。

---

## 一、目标架构总览

```
                         ┌─────────────────────────────────────┐
                         │            EditorWindow              │
                         │  顶栏 / 素材库 / 预览区 / 属性面板    │
                         └───────────────┬─────────────────────┘
                                         │
          ┌──────────────────────────────┼──────────────────────────────┐
          │                              │                               │
   ┌──────▼──────┐              ┌────────▼─────────┐            ┌────────▼────────┐
   │ TimelineView │              │ CompositionEngine │            │  PropertyPanel  │
   │ 自定义控件： │              │  给定时刻 t →     │            │  选中片段的     │
   │ 刻度/播放头/ │◄────────────►│  合成一帧画面     │            │  transform/特效 │
   │ 轨道/片段/拖拽│   编辑操作   │  + 混合一段音频   │            │  /关键帧编辑    │
   └──────┬───────┘              └────────┬──────────┘            └────────┬────────┘
          │                               │                                │
          │                      ┌────────▼─────────┐                      │
          │                      │  ClipSource ×N    │  每 clip 一个         │
          │                      │  支持 seek 的解码  │  可定位解码器          │
          │                      └────────┬──────────┘                      │
          │                               │                                 │
   ┌──────▼───────────────────────────────▼─────────────────────────────────▼─┐
   │                      DB 层（Repository + sync_oplog）                       │
   │  Project/Sequence/Track/Clip/Asset + Effect/Transition/Keyframe/Text/Export│
   └────────────────────────────────────────────────────────────────────────────┘
```

核心新增引擎组件：
- **ClipSource**：封装 FFmpeg 解封装/解码，支持任意时间 seek，按需取 RGBA 帧（区别于现有只能顺序播放、无 seek 的 `MediaPlayer`）。
- **CompositionEngine**：时间线合成器。给定时刻 t，取所有可见视频轨当前帧，按图层顺序 + transform + opacity + 特效链（libavfilter 单滤镜）+ 转场叠加，输出合成帧；同时混合该时刻所有音频轨。
- **TimelineView**：自定义 `QWidget`，自绘刻度/播放头/多轨/片段块，支持选中、拖拽、裁剪、分割、缩放。
- **PlaybackController**：播放时钟，驱动 CompositionEngine 按帧率连续出帧 + 音频送 `AudioOutput`，实现全速实时合成播放。

## 二、分阶段路线图

| 阶段 | 里程碑 | 内容 | 对应功能清单 |
|------|--------|------|--------------|
| **P1（本轮）** | 合成地基 | 补齐数据层 DAO；ClipSource（可 seek 解码）；CompositionEngine（多视频轨叠加+transform+opacity）；TimelineView 可交互控件；预览区接静帧 seek | 数据层 + A8 + H2 雏形 |
| P2 | 实时播放 | PlaybackController 播放时钟 + 多音轨混流 + 连续送帧，全速实时合成播放 | H1/H3/H5 |

| P4 | 变换属性 | 属性面板：位置/缩放/旋转/裁切/不透明度/变速/倒放/镜像/背景 | B1–B7 |
| P5 | 音频 | 音量/淡入淡出/分离/变声/降噪/EQ/波形/节拍 | C1–C9 |
| P6 | 滤镜特效 | 调色/LUT/模糊锐化/抠像/预设/暗角颗粒/马赛克（libavfilter 单滤镜对接） | D1–D7 |
| P7 | 转场 | xfade/acrossfade 系列 + 时长调节 | E1–E3 |
| P8 | 文字字幕 | 文字样式/描边阴影/SRT·ASS 导入/贴纸 | F1–F5 |

| P10 | 导出 | FFmpegEncoder 接合成引擎离线渲染 + 进度/格式/编码器/封面/GIF/片段导出 | I1–I6 |

## 三、本轮（P1）详细实现

### 1. 补齐数据访问层
`schema.sql` 已有 effect/transition/keyframe/text_element/export_job 五表，但 C++ 层缺失。

- `DbModels.h`：补 `TextElement`、`ExportJob` 两个 struct（`Effect`/`Transition`/`Keyframe` 已有）。
- `Repositories.h/.cpp`：新增 `EffectRepository`、`TransitionRepository`、`KeyframeRepository`、`TextElementRepository`、`ExportJobRepository`，沿用现有 `RepositoryBase` 的 oplog 追踪与软删除模式。

### 2. 合成引擎（src/ffmpeg 新增）
- `ClipSource.h/.cpp`：
  - `open(filePath)` → 解封装 + 打开视频解码器。
  - `frameAt(sourceUs)` → seek 到最近关键帧后逐帧解码到目标时刻，返回该帧（转 RGBA，便于叠加）。
  - 内部带「最近解码帧缓存」，相邻时刻 seek 走快路径。
- `CompositionEngine.h/.cpp`：
  - 输入：sequence 的 tracks/clips 快照（从 Repository 读）。
  - `composeAt(timelineUs)` → 找出该时刻各视频轨命中的 clip，按 `track_index` 图层序，取各自 `ClipSource` 帧，按 `clip.transform`(位置/缩放) + `opacity` 用 CPU alpha-blend 叠到画布（工程 `width×height`），输出合成 `VideoFrame`。
  - 本轮先支持视频轨叠加 + 位置/缩放/不透明度；特效/转场/关键帧留接口位（P6–P9 填充）。
  - 管理 `ClipSource` 池（按 asset 复用，避免重复打开）。
- 渲染衔接：合成画布为 RGBA → 转回 YUV420P 送现有 `VideoGLWidget`（避免改 GL；GL 多纹理叠加优化留 P2）。

### 3. 可交互时间线控件（src/widget 新增）
- `TimelineView.h/.cpp`：继承 `QWidget`，`paintEvent` 自绘：
  - 顶部时间刻度（随缩放变化）。
  - 多轨道行（轨道名 + 轨道区）。
  - 片段块（按 `timeline_start_us`/`duration_us` × 像素比例定位，显示名称/缩略色）。
  - 播放头竖线，可拖动。
  - 鼠标：点选片段（高亮）、拖播放头 seek、滚轮缩放（像素/秒）。
  - 信号：`playheadMoved(us)`、`clipSelected(clipId)`。
- 替换 `EditorWindow::refreshTimeline()` 里的 QLabel 拼块实现。

### 4. EditorWindow 接入
- 预览区把占位 QLabel 换成 `VideoGLWidget`。
- 持有 `CompositionEngine`；时间线 `playheadMoved` → `composeAt` → GL 显示。
- 添加/删除片段后重建合成引擎的 clip 快照并刷新当前帧。
- 顶栏加播放头时间码显示、逐帧前后按钮（步进，复用 composeAt）。

### 5. 样式与构建
- `theme.cpp`：新增 TimelineView 自绘所需的颜色常量（刻度/播放头/片段/选中态），属性面板基础样式。
- `CMakeLists.txt`：新增源文件由现有 GLOB 自动纳入，无需改（确认 `src/ffmpeg/source/*.cpp`、`src/widget/source/*.cpp` 已覆盖）。

### 本轮验收
- 导入多个视频→添加到多条视频轨→时间线显示片段块→拖播放头→预览区实时显示该时刻多轨叠加的合成画面（含位置/缩放/不透明度）；逐帧步进可用；编译 + 运行通过。

## 四、本轮不做（后续阶段）
实时连续播放（P2）、所有编辑交互 trim/split/拖拽（P3）、属性面板编辑（P4）、音频混流（P2/P5）、特效/转场/文字/关键帧（P6–P9）、导出（P10）。P1 只交付「合成引擎 + 可交互时间线 + 静帧 seek 预览」这一可验证地基。
